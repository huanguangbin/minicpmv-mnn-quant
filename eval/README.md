# 精度评测说明（阶段 3）

> 目标：对比四个模型（FP16 / INT8 / HQQ4 / 官方）的精度损失。
> 原则：**规模小但方法正确、可复现**，不追求大 benchmark。

## 一、文本评测（`text_qa.json`）

- **内容**：30 道中文常识/问答，覆盖地理、历史、科学、数学、文化、动物、科技 7 类。
- **格式**：`{"id", "category", "q"(问题), "a"(参考答案)}`
- **方法**：每个模型对 30 题逐一作答（greedy 采样，温度 0，保证可复现），用关键词匹配判定对错。
- **指标**：正确率 = 答对题数 / 30。

> 评分采用"参考答案关键词是否出现在模型输出中"的宽松匹配，例如参考答案"北京"，模型输出含"北京"即算对。

## 二、图像评测（`images/`）

- **内容**：2 张测试图（bus.jpg 街景、zidane.jpg 人物），后续可扩充到 10-15 张。
- **方法**：每张图让模型"用一句话描述图中内容"，对比四个模型的描述质量。
- **指标**：定性对比（描述是否准确、有无幻觉、关键物体是否识别），不强行量化——小样本下诚实记录即可。
